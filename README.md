# Concluir Tarefas

Aplicação web para gerenciamento de tarefas desenvolvida com Angular (Frontend) e Python (Backend), permitindo criar, editar, marcar como concluída e excluir tarefas.

## Stack Tecnológica

### Frontend
- Angular
- TypeScript
- HTML/CSS
- Bootstrap

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

## Funcionalidades

- Criar novas tarefas
- Editar tarefas existentes
- Marcar tarefas como concluídas
- Excluir tarefas
- Visualizar lista de tarefas
- Filtrar tarefas por status
- Interface responsiva e amigável

## Estrutura do Projeto

O projeto está dividido em duas partes principais:

### Frontend (Angular)
- Componentes reutilizáveis
- Serviços para comunicação com API
- Gerenciamento de estado
- Validações de formulário
- Rotas protegidas

### Backend (Python)
- API RESTful
- Autenticação e autorização
- Persistência de dados
- Validações
- Documentação da API
